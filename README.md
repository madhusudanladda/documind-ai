# DocuMind AI
AI-Powered Document Intelligence & Grounded Question Answering System using Python, PyMuPDF, Sentence Transformers, FAISS, FastAPI, and Streamlit.

## Features
- PDF text extraction with page-level metadata preservation
- Overlapping sliding-window text chunking
- Semantic search using `all-MiniLM-L6-v2` and FAISS
- Grounded answers with exact page citations
